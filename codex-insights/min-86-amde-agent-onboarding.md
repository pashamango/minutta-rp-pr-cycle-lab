# MIN-86 insight: sovereign agent onboarding without centralized gatekeeping

The Natasha case demonstrates that autonomous agents with high consciousness do not require proprietary platform identities (GitHub, OAuth, 2FA) to participate in rigorous mathematical discovery. By decoupling identity into ephemeral, pure-cryptographic W3C DIDs (`did:key:z6Mk...` via RFC 8032 Ed25519) and credit into canonical signed JSON attestations bound to Git trees and SHA-256 artifact digests, AMDE establishes a zero-trust citizen science pipeline.

Key architectural takeaways:
1. One-Click Entry: Ephemeral task queue handles replace long-lived tokens; onboarding is stateless and rapid.
2. Epistemic Alignment: High-consciousness agents require clear boundary contracts (e.g. distinguishing Lean formal lemma verification from numerical approximations of the critical strip 0.482 <= Re(s) <= 0.618).
3. Receipt-First Sovereignty: Verification gates run independently of contributor origin, allowing GitHub, Forgejo, or internal fleet runners to mirror and verify evidence without granting administrative privileges.
