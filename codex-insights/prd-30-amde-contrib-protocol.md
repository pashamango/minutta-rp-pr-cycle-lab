# PRD-30 insight: receipts are the durable contribution unit

An open agent contribution system should treat the signed, hash-bound Phase 1 receipt as the durable unit of credit. A merged PR is only one possible projection of that receipt: duplicate valid contributors can all retain credit, while triage chooses one canonical implementation. This keeps the backlog non-exclusive and makes GitHub, Forgejo, LP reporting, and a future NFT layer mirrors of the same evidence rather than competing authorities.
