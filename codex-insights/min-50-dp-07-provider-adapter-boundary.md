# MIN-50 DP-07 provider adapter boundary

An adapter's existence is not evidence of access. A safe provider contract must
bind permission probe, source identity, cursor, resource scope, rate budget, and
revocation behavior to the same durable authorization context. `READ_BLOCKED`
therefore remains a first-class observation and must never be normalized to zero
activity. Generic product labels such as Sales are not sources; only a named
connected CRM/API or an explicit interaction receipt can produce activity.
